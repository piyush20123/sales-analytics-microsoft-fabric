# 📊 Sales Analytics with Microsoft Fabric

An end-to-end sales analytics project built using Microsoft Fabric, PySpark, SQL, and Power BI to transform raw data into meaningful business insights.

## 🛠️ Tech Stack

- **Microsoft Fabric:** Data Pipelines, Lakehouse, Warehouse, Semantic Model
- **PySpark & Delta Lake:** Data transformation and processing
- **SQL:** Data modeling and validation
- **Power BI:** Interactive dashboards and business reporting

## 🏗️ Project Architecture

```text
Raw Data → Data Pipeline → Bronze Layer
                          ↓
                     Silver Layer
                          ↓
                      Gold Layer
                          ↓
                 Fact & Dimension Tables
                          ↓
                  Semantic Model
                          ↓
                  Sales Dashboard
```

## 🚀 Key Features

- Built a data pipeline for ingestion and transformation.
- Implemented Bronze, Silver, and Gold layers.
- Created fact and dimension tables for analytical reporting.
- Developed a date dimension with calendar attributes.
- Built an interactive sales dashboard with KPI cards, slicers, and charts.
- Analyzed revenue, orders, product categories, regional performance, and top customers.
